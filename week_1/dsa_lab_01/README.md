# DSA Lab 01 - Data Transformation Utilities

## Overview
This lab implements reusable data transformation utilities for strings, arrays, objects, and function composition.

## Files
•⁠  ⁠⁠ stringTransform.js ⁠ - capitalize, reverseString, truncate
•⁠  ⁠⁠ arrayTransform.js ⁠ - doubleArray, filterEven, sumArray
•⁠  ⁠⁠ objectTransform.js ⁠ - keys, values, invert
•⁠  ⁠⁠ functionComposition.js ⁠ - compose, pipe

## How to Run
```bash
node -e "const s = require('./stringTransform'); console.log(s.capitalize('hello'))"
node -e "const a = require('./arrayTransform'); console.log(a.doubleArray([1,2,3]))"ßß
